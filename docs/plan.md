# 開発計画書: Line Key Label 機能拡張

## 全体方針
- **SSOTの堅持**: `project/*.json` は初期値（デフォルト）として扱い、アプリ上の変更は React state を唯一の真実として扱う。
- **ハードコーディングの排除**: 色・文言・設定値はすべて `config` / `constants` に集約し、DRY を保つ。
- **分離**: UI（React）と Core（計算/変換ロジック）を明確に分離してテスト可能性を担保する。
- **段階的な実装**: 影響が少ない変更から順に進める。

## フェーズ1: 設定の集約とリファクタリング（基盤整備）
**目的**: UI 変更が局所的になる土台を作る。

### タスク
1. `src/config/uiConfig.ts`（仮）を追加し、配色・サイズ・スライダー範囲を集約。
2. `src/constants/uiText.ts`（仮）を追加し、UI 文言を集約。
3. `App.tsx` / `PanelCanvas.tsx` の直書き値を上記に置換。

### 成果物
- UI 文言・色の一元化。
- 後続のデザイン変更の影響を最小化。

---

## フェーズ2: 台紙（スキャン画像）取り込み・テンプレート化
**目的**: 実物の穴あきシートに合わせるための台紙を使い、再利用できるテンプレートを確立。

### タスク
1. 画像アップローダー（ドラッグ&ドロップ対応）
2. Konva の **最背面**に台紙レイヤーを追加
3. 不透明度調整スライダー
4. 実寸合わせ（2点距離指定によるスケール補正）
5. **台紙テンプレート保存**
   - 台紙画像 + 位置/スケール/回転 + キャリブレーションを保存
   - 保存先は IndexedDB 等（SSOT は state、保存は永続化）
6. **テンプレート一覧・再利用 UI**
   - 既存テンプレートを選択して復元

### 重要事項
- **歪み補正は行わず**、位置とスケールの調整に限定。
- 精度目標: ±0.3mm（補正は手動前提）。

---

## フェーズ3: デザイン編集（Data & Design）
**目的**: data.csv と design.json を編集可能にし、再編集できる形でエクスポート/インポートする。

### タスク
1. CSV 読み込みと Text 配置
2. フォント変更（Web フォント適用）
3. 背景色・枠線色のピッカー
4. **デザインのエクスポート/インポート**
   - design.json 形式を優先
   - CSV 兼用が可能なら mapping を併用
5. インポート後の state 復元と再編集 UI

---

## フェーズ4: 印刷位置調整と PDF 出力
**目的**: 正確な寸法で PDF を生成する。

### タスク
1. `calibration/printer_profile.json` の調整 UI
2. `createBlankPdf` を拡張し `createPrintPdf` を実装
3. pdf-lib による正確な PDF 生成

### 重要事項
- **台紙レイヤーは印刷対象外**（デザイン時のみ表示）
- PDF 出力は design + offset のみを反映

---

## 台紙の表示/印刷ポリシー（再確認事項）
- 台紙は **位置合わせのための参照レイヤー**。
- **表示/非表示トグル**を持ち、デザイン時のみ必要。
- **印刷時は必ず無視**する（PDF には含めない）。

---

## 付録: 影響が少ない順の実装順序
1. UI config / text の外部化
2. 台紙レイヤー追加（表示・不透明度）
3. 台紙テンプレート保存/再利用
4. デザインのインポート/エクスポート
5. PDF 出力の印刷仕様対応
