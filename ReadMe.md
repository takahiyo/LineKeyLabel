# 示名条片デザインWebアプリ 開発指示書

> **AIコーディング向け要件定義**  
> A4横2×2パネル、±0.3mm精度、CSV差し込み対応

---

## 1. 開発原則

### SSOT（Single Source of Truth）厳守
- データは必ず1箇所で定義、他は参照のみ
- 計算値のキャッシュ禁止（不整合の原因）
- UI状態とデータモデルの分離

### モジュール化要件
- 1モジュール = 1機能（単一責任）
- 疎結合・高凝集
- 各関数に以下を明記：
  - `@ssot` : どのファイルがSSoTか
  - `@accuracy` : 精度要件
  - `@algorithm` : 処理概要

### 精密制御要件
- **穴余白**：0.5〜2.0mm（0.1mm刻み調整）
- **既定値**：1.0mm（ボタン穴間距離≈6mmのため）
- **限界値**：0.5mm未満は物理的に危険

## 4. 主要機能

### 4.1 スキャン → テンプレート生成
1. **入力**：PNG/JPG/PDF（300dpi推奨）
2. **正置**：切り落とし角を検出 → 左90°回転
3. **補正**：四隅で射影補正 → A4横正規化
4. **枠検出**：Hough直線 → 2×2分割（精度±0.5mm）
5. **穴検出**：円/角/長孔を自動検出
6. **保存**：`panel-template.json`

### 4.2 穴回避レイアウト
1. **NG領域**：穴を余白（0.5〜2.0mm）で膨張
2. **安全領域**：パネル矩形 − NG領域
3. **自動配置**：
   - 最短移動で被り解消
   - 不可ならフォント縮小
   - 不可なら改行
4. **検証**：最小距離≧設定閾値

### 4.3 CSV差し込み
- トークン `{name}` で要素にマッピング
- 展開モード：同一行4面 / 連番4行

### 4.4 PDF出力
- A4横、2×2面付、フォント埋め込み
- 実寸100%印刷を誘導

## 5. アルゴリズム要点

### 回転正置
```
1. 四隅10×10mm領域で斜め直線検出
2. 最も明確な切り落とし角を特定
3. その角が左上に来る回転角を決定
```

### パネル枠検出
```
1. Canny → Hough直線
2. 水平/垂直線に分類・クラスタリング
3. スコアリングで縦1・横1の分割線決定
4. 4矩形生成 → mm座標変換
```

### 穴回避配置
```
1. 各穴を余白（mm）で膨張 → NG領域合成
2. 要素を既定位置に配置
3. 被りあり → 螺旋探索で最短移動（0.1mm刻み）
4. 不可 → フォント縮小（最小サイズまで）
5. 不可 → 改行
```

## 6. 設計ガイドライン

### アーキテクチャ
```
[Presentation] ← Props/Events
[Application]  ← Commands/Queries
[Domain]       ← Entities/ValueObjects
[Infrastructure] (Storage/PDF/Image)
```

### SSOT実装パターン
```typescript
// ❌ 悪い例：複製
const data = { ...template };

// ✅ 良い例：参照
const template = await repo.findById(id);
```

### 禁止事項
- グローバル変数
- `any` 型の乱用
- データの直接変更（Mutation）
